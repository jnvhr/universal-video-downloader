# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React, Vite, Tailwind CSS v4, Express, Node.js, yt-dlp

## Users

Individuals wanting to quickly and reliably download video or audio from social platforms and video sharing sites (YouTube, X / Twitter, Vimeo, etc.) without ads, spam, popups, or quality throttling.

## Product Purpose

A universal, high-craft web tool that parses video URLs, shows all detected video formats and multi-video attachments, and streams downloads cleanly with real-time feedback.

## Positioning

Minimalist, distraction-free, native-feeling utility running on yt-dlp, with zero clutter and instant feedback.

## Operating Context

Modern desktop and mobile web browsers. Fast paste-to-download loop.

## Capabilities and Constraints

- Extracts video metadata, thumbnails, multi-video posts/playlists via yt-dlp.
- Real-time download progress via Server-Sent Events (SSE).
- Quality/format selection and audio extraction (MP3).
- Responsive macOS-inspired interface.

## Brand Commitments

- Aesthetic: Modern macOS/iOS native feel, clean typography, refined depth, subtle micro-interactions.
- Voice: Direct, functional, calm, no marketing fluff.

## Product Principles

1. Immediate utility: The input field is the primary affordance.
2. Clear visibility: Always show video duration, thumbnails, resolution, and real-time progress.
3. Native craft: Interactions feel as responsive and solid as desktop system software.
